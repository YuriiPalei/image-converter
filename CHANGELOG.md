# Image to WebP Converter Changelog

## [Unreleased]

## [1.1.2]

### Added

- Added support for IDE version 2026.1.*

## [1.1.1]

### Added

- Added support for IDE version 2025.3.*

## [1.1.0]

### Added

- Added support for IDE version 2025.2.*
- Added support of native conversion for PNG and JPEG images.

### Fixed

- Fixed the issue with converting from JPEG format.

### Changed

- Migration from Kotlin to Java.

## [1.0.4]

### Added

- Added support for IDE version 2025.1.*

## [1.0.3] - 2025-02-25

### Added

- Fixed error "invalid plugin descriptor jetbrains plugin"

## [1.0.2] - 2025-01-23

### Added

- Added support for IDE version 251.*

## [1.0.1] - 2024-12-06

### Added

- Added support for IDE version 2024.3.*

## [1.0.0] - 2024-09-04

### Added

- Initial release of the Image to WebP Converter plugin.
- Convert JPEG and PNG images to WebP format.
- Batch file processing for up to 5 files.
- File size preview and automatic file system refresh.
